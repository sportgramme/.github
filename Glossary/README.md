# Glossary

Shared definitions for the Sportgramme documentation — betting-market terms,
data-platform terms, and the analytics framework.

It is split by the term's **first letter** so each file stays small as the
glossary grows. Add a term to the file for its letter, keeping entries in
alphabetical order.

| File | Letters |

| [A–C](A-C.md) | A B C |
| [D–F](D-F.md) | D E F |
| [G–I](G-I.md) | G H I |
| [J–L](J-L.md) | J K L |
| [M–O](M-O.md) | M N O |
| [P–R](P-R.md) | P Q R |
| [S–U](S-U.md) | S T U |
| [V–Z](V-Z.md) | V W X Y Z |

## Conventions

- One `### Term` heading per entry, so it can be linked directly
  (`Glossary/S-U.md#tick-data`).
- Keep definitions plain-language first; a second sentence may add precision.
- Cross-reference with **bold** term names and a link to the file, e.g.
  see **[verdict](V-Z.md#verdict)**.
- When a file gets long, split its letter range further (e.g. `A-C.md` →
  `A.md`, `B.md`, `C.md`) and update this index.
