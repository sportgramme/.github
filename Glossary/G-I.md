# Glossary — G–I

**Index:** [A–C](A-C.md) · [D–F](D-F.md) · G–I · [J–L](J-L.md) · [M–O](M-O.md) · [P–R](P-R.md) · [S–U](S-U.md) · [V–Z](V-Z.md) · [about](README.md)

### Governed asset library

The managed store of first-party stills, video and audio, foldered by sport
taxonomy, with a distinct set marked for syndication. Contributions enter only
through the media pipeline; nothing is admitted without passing pre-flight checks
and, for probationary contributors, the **[moderation gate](M-O.md#moderation-gate)**.

### Hypothesis

A precise, testable question, written down once (as a `hypothesis.yaml`) so the
identical analysis can be re-run any time new data arrives. It carries its
statement, the data it needs, the statistical test to use, and the
**[decision rule](D-F.md#decision-rule)** for reaching a **[verdict](V-Z.md#verdict)**.

### Implied probability

A decimal price expressed as a chance: `p = 1 / decimal odds`. Analyses work in
this space so that a short price (2.0) and a long price (50.0) can be compared on
the same scale.

### In-play

A match currently live. Widgets filter to in-play matches for compact "live right
now" views; a result is never fabricated for a match still in play.
