# Sportgramme — Contributor Journey

| Journey              | Contributor Action                               | Sportgramme Adds                                                                                   | Result                                                                 |
| -------------------- | ------------------------------------------------ | -------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------- |
| **Join**             | Create a contributor profile                     | Identity, expertise, sports and disciplines                                                        | Professional contributor identity                                      |
| **Discover**         | Find sports, events and opportunities            | Global sports calendar and event data                                                              | More opportunities to cover                                            |
| **Collaborate**      | Work with other contributors                     | Collaboration tools, shared event context and connected data                                       | Richer coverage                                                        |
| **Create**           | Produce article, photo, video, audio or analysis | Contributor workflow and production tools                                                          | Original submission                                                    |
| **Submit**           | Upload work to Sportgramme                       | Structured submission workflow                                                                     | Submission enters the Sportgramme ecosystem                            |
| **Identify**         | Tell Sportgramme what the submission is about    | Sport, discipline, competition, event, athlete, team, venue and organisation metadata              | Content becomes structurally identifiable                              |
| **Enrich**           | Add context to the submission                    | Sportgramme metadata, identifiers, schedules, results, rankings, statistics and historical context | **Enhanced submission**                                                |
| **Validate**         | Confirm accuracy and provenance                  | Data validation, source information, timestamps and provenance                                     | Higher-confidence content                                              |
| **Optimise**         | Prepare content for consumption                  | Structured metadata, categorisation, tagging, descriptions and related entities                    | **Higher-quality, more discoverable content**                          |
| **Publish**          | Release the contribution                         | Sportgramme publishing infrastructure                                                              | Immediate availability to Sportgramme audiences                        |
| **Syndicate**        | Make content available to partners               | Standardised metadata and syndication-ready packaging                                              | Easier partner consumption                                             |
| **Distribute**       | Reach wider audiences                            | Publishers, broadcasters, platforms, APIs and commercial partners                                  | **Reach beyond the contributor's own network**                         |
| **Repurpose**        | Create additional formats                        | Structured data and metadata                                                                       | Articles, feeds, summaries, social content, datasets and other formats |
| **Measure**          | Understand performance                           | Reach, engagement and syndication analytics                                                        | Evidence of commercial and audience value                              |
| **Monetise**         | Generate revenue                                 | Licensing, syndication and commercial distribution                                                 | Additional income opportunities                                        |
| **Build Reputation** | Demonstrate expertise                            | Attribution, portfolio and contribution history                                                    | Growing professional profile                                           |
